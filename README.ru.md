# BO6 Personal Progress

[English](README.md) · [Скачать готовый ZIP](https://github.com/queerkorol-ux/bo6-personal-progress/releases)

Готовый ZIP релиза уже содержит EXE и всю рабочую папку. Сборка нужна только
для исходников; для готового релиза переходи сразу к установке с пункта 1.

Личный офлайн-прогресс кампании и локальные контрольные точки для **конкретной
совместимой установки BO6**. Рабочий код — **0.2.4**, EXE-запускатель — **0.3.5**.
Пользователь подтвердил работу этой конфигурации. Полное прохождение кампании
и другие сборки не проверены.

## Возможности и ограничения

Отдельные деньги, прогресс и контрольные точки; восстановление обычных условий
доступа вместо принудительного полного открытия совместимой установки.
Существующие личные данные не сбрасываются. Перед запуском создаётся проверенная
резервная копия фиксированных файлов профиля и слотов.

Анимация сохранения запускается как раньше, но только её виджет скрывается
примерно через две секунды таймеров интерфейса. **Это таймер видимости, а не
подтверждение записи.** На паузе таймеры могут останавливаться. Красная ошибка
записи в консоли означает, что последний новый прогресс не подтверждён,
независимо от надписи в игре.

EXE/DLL игры на диске не переписываются. Патч изменяет **память запущенного
процесса**, включая проверенные участки сохранения/прогресса и обработчик
загрузки Lua. Окно патча должно оставаться открытым до обычного выхода из BO6.

## Требования

Windows x64, Windows PowerShell 5.1, .NET Framework 4.x, администратор и уже
работающая совместимая офлайн-установка с `!start_sp24.bat` и
`sp24/sp24-cod.exe`. Запускай под **той же учётной записью Windows, что и игру**,
включая подтверждение UAC. Просто повысить права другой учётки недостаточно.

SHA256 изученного EXE:

```text
18360ffef4f9dccd2f16106a8afe5111d3bf2fa5ace9430f9e4b28e9af6342d6
```

Нужен также исходный совместимый Lua-обработчик существующего
`discord_game_sdk.dll`: RVA `0x4037B0`, размер `0x720`, SHA256
`9862a33e05b09ee4be3ca7a4e950178851ecd235f1e2f3cf5091609e53b55b88`.
Действуют дополнительные проверки кода и структур. Совпадения одного EXE
недостаточно. Не отключай проверки ради другой сборки. Ранний этап должен
выполниться до загрузки Lua, поэтому запускай с закрытой игрой.
Это не универсальный патч розничной/сетевой версии. Игра, компоненты
авторизации, эмулятор, игровые DLL и драйверы здесь не распространяются.

## Сборка EXE и установка

Из корня репозитория в Windows PowerShell:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Build-Launcher.ps1
```

Используется штатный x64-компилятор .NET Framework, manifest `asInvoker`
встраивается автоматически. Компилятор другой версии/даты может дать другой
хеш EXE. Готовый EXE не хранится в исходном репозитории. После публикации GitHub Release
Windows CI собирает и прикрепляет готовый ZIP, если офлайн-проверки пройдены.
`scripts/New-Release.ps1` собирает такой же комплект локально строго по списку
файлов, без рекурсивного включения личных данных.

1. Закрой BO6 обычным способом и старое окно патча.
2. Скопируй существующую **`BO6_Personal_Progress_Data`** в резервную копию.
3. Положи папку `BO6_Personal_Progress` в папку игры рядом с `sp24` и BAT.
   При обновлении заменяй код; отдельную папку Data **не удаляй и не заменяй**.
4. Запусти `Run_BO6_Personal_Progress.cmd` или собранный
   `Run_BO6_Personal_Progress.exe`; разреши запуск под игровой Admin-учёткой.
5. Дождись **ПАТЧ АКТИВЕН**, выбери свой личный слот и продолжай.
   Если Data ещё нет, создаётся отдельный новый личный профиль кампании.

Для приложения учёта времени выбери
`<папка игры>\BO6_Personal_Progress\Run_BO6_Personal_Progress.exe`.
Исходный процесс EXE ждёт повышенную копию, затем PowerShell и всю сессию.
После обычного выхода игра/патч завершаются без финального ENTER для EXE;
у CMD прежнее поведение. Подсчёт часов конкретным приложением надо проверить.
EXE требует остальную папку, это не однофайловый комплект. Не закрывай его
принудительно во время игры.

## Данные и ошибки

`<папка игры>/BO6_Personal_Progress_Data/` содержит `campaign.bo6profile`,
`slot1.bo6local`—`slot3.bo6local`, `.bak`, `backups/` и `logs/`.
Не публикуй эти файлы или диагностические ZIP. Не удаляй профиль для
исправления ошибки контрольной точки. Сохраняй резервные копии.

Успешная локальная запись отражается отдельно в консоли. При красной ошибке
последний новый прогресс не подтверждён: сохрани логи и резервные копии.
Если Lua виджета отличается, пропускается только визуальное изменение,
сохранение продолжает работать. Логи EXE —
`%LOCALAPPDATA%/BO6_Personal_Progress_Launcher` запускавшей учётки; повышенная
копия под другим пользователем может записывать свой лог отдельно.

## Если Defender блокирует запись настроек

Только при подтверждённом событии **1123** в Defender Operational, где указан
именно игровой EXE и папка настроек, можно разрешить приложению запись через
Controlled Folder Access. Сначала закрой игру, затем в PowerShell администратора:

```powershell
$exe='C:\Games\Call of Duty. Black Ops 6\sp24\sp24-cod.exe'
if (-not (Test-Path -LiteralPath $exe -PathType Leaf)) {throw 'Проверь путь игры'}
Add-MpPreference -ControlledFolderAccessAllowedApplications $exe
```

После этого перезапусти игру. Добавляется только разрешение указанному EXE;
список других приложений не заменяется, антивирусное сканирование не отключается.
Не разрешай PowerShell и не отключай Defender/CFA. Сам проект не меняет
параметры защиты. Документация Microsoft:
[события CFA](https://learn.microsoft.com/en-us/defender-endpoint/controlled-folder-access-monitor),
[разрешение приложению](https://learn.microsoft.com/en-us/powershell/module/defender/add-mppreference).

## Откат

Обычно закрой BO6, затем патч. Его изменения памяти исчезают вместе с процессом.
Запускай исходный `!start_sp24.bat`, а не Personal Progress. Папку кода можно
убрать после закрытия; Data оставь в резервной копии, пока не решишь сознательно
удалить личный прогресс. Это не установщик исходных файлов игры, не очистка
экспериментов, не MFG и не сброс параметров защиты Windows.

## Проверки и лицензия

`tests/Test-Offline.ps1` проверяет синтаксис PS, неизменность 11 файлов,
компиляцию семи C#-исходников, форматы/контрольные суммы и виджет.
Игровой процесс, личные сейвы и нативный обработчик в этих тестах не открываются
и не выполняются. Windows CI также собирает EXE. CI не заменяет проверку
реальной игры или полное прохождение. Перед игрой рабочий патч отдельно
выполняет свой ограниченный нативный self-test в собственном дочернем процессе.

Рабочие runtime-файлы побайтово сохранены от v024; их хеши закреплены в адаптере.
При изменении исходников надо согласованно пересматривать проверки, а не ослаблять их.
MIT распространяется только на оригинальный авторский код. Встроенные
game-derived байты совместимости и Lua-фикстур не получают MIT-лицензию;
подробности — [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
